# Design source

`mockup/` holds the Flowlane prototype screens from the design canvas (`.dc.html` files).
They need the canvas runtime to render, so open them in the original canvas rather than a browser.
They are kept here as the visual reference the React app in `frontend/` was built from:

- `Brand.dc.html`: logo, palette (jet black, cerulean, neon rose) and type
- `App.dc.html`: the full interactive prototype; the other files open it on a specific screen
